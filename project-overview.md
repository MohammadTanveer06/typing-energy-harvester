# Project Overview

## Title
**Typing Energy Harvester Using Piezoelectric Elements**

## Problem statement

Every keystroke applies a small mechanical force to a keyboard. Most of this mechanical energy is dissipated as vibration, sound, heat, and deformation. This project investigates whether a small fraction can be converted into usable electrical energy.

## Proposed solution

Piezoelectric elements are mechanically coupled to a keyboard structure. When the elements experience deformation or vibration, they generate an electrical signal. A rectifier converts the signal into one direction, and a capacitor stores the harvested charge.

## Key engineering questions

1. Does increasing typing force increase harvested voltage?
2. Does increasing the number of piezo elements improve the charging rate?
3. Which capacitor size produces the most measurable voltage rise?
4. How repeatable are the measurements?

## Success criterion

The prototype is successful when typing produces a measurable increase in storage-capacitor voltage and the system can calculate the corresponding stored energy.
