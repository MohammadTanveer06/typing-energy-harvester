# Upload This Project to GitHub — Very Easy

Your repository already exists:

`https://github.com/MohammadTanveer06/typing-energy-harvester`

## On your phone

1. Open GitHub in Chrome.
2. Open your `typing-energy-harvester` repository.
3. Tap **Add file**.
4. Tap **Upload files**.
5. Select the downloaded project files/folders from this package.
6. Scroll down.
7. Tap **Commit changes**.

### Important

For GitHub to keep the folder structure correctly, upload the **contents of this project folder**.

After uploading, your GitHub page should show:

- `docs`
- `firmware`
- `hardware`
- `software`
- `simulation`
- `measurements`
- `presentation`
- `README.md`

## Easiest computer method

1. Download the ZIP.
2. Extract it.
3. Open your GitHub repository.
4. Select **Add file → Upload files**.
5. Drag all extracted files/folders into the upload area.
6. Click **Commit changes**.

## After upload

Open `README.md` first. It tells you where each part is.

Then open:

`hardware/components.md`

and

`hardware/wiring.md`

to build the prototype.

## What you still need to physically build

GitHub can store the design/code/documentation, but it cannot physically build the circuit. You need the listed components and a keyboard for the experiment.

Do not enter fake experimental results. Measure your actual voltage values and put them into `measurements/raw_data.csv`.
